# xc-tagger · 星川服务商达人自助打标工具 v3

> 在自己电脑上运行的小工具：用**你本人的巨量星图账号**，批量给达人名单打分分层。
> 全流程 **3 步**，无需安装任何浏览器插件、无需导出 Cookie。

---

## 使用步骤（3 步搞定）

### 第 1 步：安装并启动工具

- **Mac**：解压后双击 `start-xc-tagger.command`
- **Windows**：解压后双击 `start-xc-tagger.bat`
- 首次运行会自动安装依赖（需已安装 **Node.js 18+**，未安装请先到 https://nodejs.org 下载安装）
- 启动成功后会看到黑色窗口显示「本地工具已启动 v3.0.0」，**保持窗口打开**，然后回到工作台网页

### 第 2 步：登录星图（仅需一次）

在「星川决策工作台」网页点 **「🚀 登录星图」** 按钮，本机会弹出一个 Chrome 浏览器窗口：

1. 在窗口里用**手机星图 App 扫码**（或手机号验证码）登录巨量星图；
2. 登录成功后窗口**自动关闭**，登录状态保存在本机，网页提示「✅ 登录成功」；
3. 下次使用无需重复登录（除非登录态过期，过期后再点一次按钮扫码即可）。

### 第 3 步：上传达人名单并打标

1. 准备 Excel / CSV 名单，包含「**达人ID**」（星图达人 ID 数字）或「**昵称**」列即可
   （可下载工作台提供的 `xc-influencer-template.xlsx` 模板）；
2. 把文件上传到工作台，点「**开始打标**」；
3. 等待逐人抓取打分，完成后在线查看分层结果，并可**一键导出 CSV**。

打标时浏览器在**后台无头运行**，不会弹窗打扰；只有第 2 步登录时会弹窗。

## 打标口径（与存量达人库对齐）

工具逐人抓取星图公开信息，按 **80 分制**自动打分并分四层：

| 维度 | 分值 | 口径 |
|---|---|---|
| 星川达人等级 | 30 | S5=30 / S4=25.5 / S3=21 / S2=15 / S1=9 / S0=4.5 |
| 星图消耗 | 20 | >100万=20 / 10-100万=16 / 1-10万=12 / 0.1-1万=8 / 0=0 |
| 交付项目数 | 20 | >50个=20 / 21-50=15 / 6-20=10 / 1-5=5 / 0=0 |
| 电商等级 | 10 | L3+=10 / L2=7 / L1=4 / L0=1 |

**分层**：≥60 分 🥇标杆 ｜ ≥40 分 🥈主力 ｜ ≥20 分 🥉潜力 ｜ <20 分 ⚪储备

人设标签、内容形式、行业标签均按存量达人库的固定选项输出，结果 CSV 可直接回填达人库。

## 系统要求

- **Node.js 18 或以上**（https://nodejs.org）
- Windows 10/11 或 macOS 12+
- 正常的电脑桌面环境（登录时需要弹出浏览器窗口，不能在无图形界面的远程服务器上运行）

## 常见问题

- **双击启动脚本没反应 / 一闪而过**：请先确认已安装 Node.js 18+；Windows 可在文件夹地址栏输入 `cmd` 回车后运行 `node xc-tagger.js` 查看报错。
- **点「登录星图」后没有弹出窗口**：检查是否被安全软件拦截；确认是在自己电脑桌面环境运行（不能是远程无桌面服务器）。
- **扫码后窗口没自动关闭**：确认扫码登录的是**巨量星图**账号并已进入达人广场；超过 3 分钟会自动超时，重新点一次按钮即可。
- **打标时提示未登录**：登录态可能已过期，重新点「🚀 登录星图」扫码即可。

## 隐私说明

- 登录状态保存在工具目录的 `.xc-cookies.json` 文件中，**不上传、不落库、不经过任何服务器**；
- 抓取动作发生在你自己的电脑上，工作台网页只与本机 `127.0.0.1:7842` 通信；
- 删除 `.xc-cookies.json` 文件即退出登录。
