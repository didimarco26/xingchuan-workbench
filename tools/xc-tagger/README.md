# 星川服务商达人自助打标 · 本地工具 (xc-tagger)

> 在自己电脑上运行的小工具：用**你本机已登录的星图账号**，批量给达人名单打分分层。
> 登录态 / Cookie **只留在你自己的电脑**里（`.xc-chrome-profile/` 文件夹），不上传、不落库。

---

## 一、它能做什么

1. 在本机起一个小服务 `http://127.0.0.1:7842`；
2. 自动打开一个 Chrome，用 Playwright 保存登录态，**首次扫码登录巨量星图一次**，之后长期免登录；
3. 在「星川决策工作台·服务商」网页（GitHub Pages）里上传 Excel/CSV 达人名单，点「开始打标」；
4. 网页调用本机服务，工具用星图登录态抓取每位达人的 **星川等级 / 交付项目数 / 星图消耗 / 电商等级**，按存量达人逻辑自动打分、分层，结果可导出 CSV。

### 打标规则（与存量达人一致）

| 维度 | 满分 | 分档 |
| --- | --- | --- |
| 星川等级 S | 30 | S5=30 / S4=25.5 / S3=21 / S2=15 / S1=9 / S0=4.5 |
| 交付项目数 | 20 | >50=20 / 21–50=15 / 6–20=10 / 1–5=5 / 0=0 |
| 星图消耗 | 20 | >100万=20 / 10–100万=16 / 1–10万=12 / 0.1–1万=8 / 0=0 |
| 电商等级 L | 10 | L3 及以上=10 / L2=7 / L1=4 / L0=1 |

**分层（按总分，满分 80）**：🥇 标杆 ≥60 ｜ 🥈 主力 ≥40 ｜ 🥉 潜力 ≥20 ｜ ⚪ 储备 <20

## 二、一键运行（推荐，需装 Node.js）

1. **安装 Node.js 18+**：到 <https://nodejs.org> 下载 LTS 版本，一路下一步安装。
2. 把本文件夹（`xc-tagger`，内含 `package.json`、`xc-tagger.js`）放到电脑任意位置。
3. 在该文件夹里打开终端（Windows：在文件夹地址栏输入 `cmd` 回车；Mac：右键「服务→在文件夹位置打开终端」），执行：

   ```bash
   npm install        # 首次运行，会自动装好 Playwright 的 Chromium 浏览器
   node xc-tagger.js  # 启动工具
   ```

4. 首次启动会弹出 Chrome 并打开「巨量星图 · 达人广场」，**用手机扫码 / 验证码登录一次**即可（登录态保存在本文件夹，下次免登）。
5. 保持这个黑窗口**不要关**，回到网页 `https://didimarco26.github.io/xingchuan-workbench/`，
   进入「🏷️ 服务商达人自助打标」板块，页面显示「✅ 本地工具已连接」后即可上传名单、开始打标。

> 关闭工具：在黑窗口按 `Ctrl + C`。

---

## 三、名单文件格式

支持 **.xlsx / .xls / .csv**，第一行为表头，工具自动识别下列列（命中其一即可）：

- 达人 ID 列：列名含 `达人ID / 星图ID / ID / UID / 编号`（纯数字，星图达人 ID）
- 昵称列：列名含 `昵称 / 达人名 / 名字 / 账号名 / name / 主播`

只有一列时：纯数字按「达人 ID」处理，否则按「昵称」处理。
- 有 **达人 ID** 走批量接口（50 个/批，更快更准）；
- 只有 **昵称** 走达人广场搜索匹配。

## 四、打包成 exe（可选，发给不懂 Node 的同事）

在已装 Node 的电脑上，用 [pkg](https://github.com/vercel/pkg) 打包：

```bash
npm install -g pkg
pkg xc-tagger.js --targets node18-win-x64 --output xc-tagger.exe
```

> 注意：pkg 不会自动带上 Playwright 的浏览器。分发 exe 时，需让同事机器上装有 Chrome / Edge，
> 或额外随包附带 Chromium。**最省事的方式仍是让同事装 Node 后 `npm install`**。
> 使用者数据（登录态）始终在工具同目录的 `.xc-chrome-profile/` 内，删除该文件夹即完全退出登录。

## 五、常见问题

- **网页提示「❌ 本地工具未启动」**：确认黑窗口还在运行；或工具端口被占用（关掉占用 7842 的程序）。
- **提示「星图未登录」**：切到弹出的 Chrome 窗口，重新扫码登录，再点「重新检测 / 开始打标」。
- **某位达人「未检索到」**：昵称拼写不一致、或该达人未入驻星图；有达人 ID 时尽量用 ID 列。
- **想彻底退出登录**：删除本文件夹下的 `.xc-chrome-profile` 目录后重启工具。
- **抓取字段对不上 / 想排查**：设置环境变量 `XC_TAGGER_DEBUG=1` 再启动，会把星图原始响应落盘为 `debug_*.json`，反馈给维护者即可快速校准字段映射。

## 六、安全说明

- 服务**只绑定 `127.0.0.1`**（本机回环），局域网其它电脑访问不到；
- 跨域 (CORS) 仅放行 `didimarco26.github.io` 与本机页面，其它网站无法调用你的本地服务；
- 不收集、不上传任何名单或登录数据；所有抓取与打分都在你本机完成。
