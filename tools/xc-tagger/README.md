# xc-tagger · 星川服务商达人自助打标工具 v3.5

> 在自己电脑上运行的小工具：用**你本人的巨量星图账号**，批量给达人名单打分分层。
> 全流程 **3 步**，无需安装任何浏览器插件、无需导出 Cookie。
> **v3.5 新增「达人主页视频分析」+ 双库口径打分**：打标时工具会逐个进入达人主页，
> 自动抓取**前三个视频**的标题/播放量/内容形式，结果里带 `视频分析`；视频内容方向
> 会反哺标签。评分兼容两个库——**存量库**名单保持 80 分制；**增量库/新达人**在基础分上
> 叠加视频分析加分（带货视频、口播测评种草、播放超 10 万，最多 +20，封顶 100），结果带
> `数据来源`（存量库/增量库/未在库）与 `视频加分`。
> 登录仍为 v3.4 方案：点「登录星图」后**每 3 秒主动检查浏览器所有标签页**，扫码/账号密码/
> 验证码均可，进入星图创作者区域即判成功并**自动关闭窗口**。运行依赖已内置，**解压即用**。

## 使用步骤（3 步搞定）

### 第 1 步：下载并启动工具

- 在工作台网页下载**一键启动包**：Mac 下载 `xc-tagger-mac-v1.zip`，Windows 下载 `xc-tagger-win-v1.zip`
  （不确定系统就下通用包 `xc-tagger-v1.zip`）
- **解压完整**（保留包内全部文件，不要只拖出启动脚本）后：
  - **Mac**：双击 `start-xc-tagger.command`
  - **Windows**：双击 `start-xc-tagger.bat`
- 启动包已内置全部运行依赖（node_modules），**不需要联网安装**；仅需电脑满足：
  - 已安装 **Node.js 18+**（未安装请到 https://nodejs.org 下载，装好后重新双击启动脚本）
  - 装有 **Google Chrome 或 Microsoft Edge**（Windows 10/11 自带 Edge，一般无需额外安装）
- 启动成功后黑色窗口会显示「本地工具已启动 v3.5.0」，**保持该黑色窗口打开**，然后回到工作台网页
  （登录时弹出的 Chrome/Edge 浏览器窗口在登录成功后会**自动关闭**，属正常现象）
- Mac 首次双击如提示「无法打开，因为来自身份不明的开发者」：在启动脚本上**右键 → 打开**一次即可；
  Windows 如弹出安全提示，选「仍要运行」（工具只与本机通信，不上传任何数据）

### 第 2 步：登录星图（仅需一次）

在「星川决策工作台」网页点 **「🚀 登录星图」** 按钮，工具会自动选择最稳的方式登录：

**方式 A（默认）：系统浏览器窗口登录**
- 工具自动打开你电脑上的 **Chrome / Edge 窗口**（优先 Chrome，其次 Beta/Canary、Edge、Chromium）；
  如果窗口在你点按钮前就已经开着，工具会**直接复用该窗口**，不重复弹新窗；
- 在窗口里用**手机抖音 / 星图 App 扫码**、**账号密码**或**手机号验证码**登录巨量星图均可，
  **在哪个标签页登录都可以**，工具每 3 秒自动检查所有标签页；
- 登录成功后网页提示「✅ 登录成功」，**浏览器窗口会自动关闭**（登录态已保存在本机；
  打标时工具会在后台自动重开浏览器工作，无需你操作，也不用再登录）。

**方式 B（企业环境兜底）：网页内二维码扫码**
- 如果公司电脑的安全策略**禁止自动启动浏览器窗口**（窗口一闪而过 / 被秒关），工具会自动降级：
- 工作台网页上会**直接显示一张登录二维码**，拿出**手机抖音 App → 扫一扫**即可登录；
- 全程不弹窗、不依赖系统浏览器自动化，同样只需一次。

> 下次使用无需重复登录（除非登录态过期，过期后再点一次按钮即可）。

### 第 3 步：上传达人名单并打标

1. 准备 Excel / CSV 名单，包含「**达人ID**」（星图达人 ID 数字）或「**昵称**」列即可
   （可下载工作台提供的 `xc-influencer-template.xlsx` 模板）；
2. 把文件上传到工作台，点「**开始打标**」；
3. 等待逐人抓取打分，完成后在线查看分层结果，并可**一键导出 CSV**。

打标时工具会在后台自动打开浏览器工作（屏幕上可能短暂出现工作标签页，属正常现象）；只有第 2 步登录时需要你操作。

## 打标口径（双库兼容）

工具逐人抓取星图公开信息并**进入达人主页分析前三个视频**，自动打分并分四层。

### 基础分（80 分制，所有达人一致）

| 维度 | 分值 | 口径 |
|---|---|---|
| 星川达人等级 | 30 | S5=30 / S4=25.5 / S3=21 / S2=15 / S1=9 / S0=4.5 |
| 星图消耗 | 20 | >100万=20 / 10-100万=16 / 1-10万=12 / 0.1-1万=8 / 0=0 |
| 交付项目数 | 20 | >50个=20 / 21-50=15 / 6-20=10 / 1-5=5 / 0=0 |
| 电商等级 | 10 | L3+=10 / L2=7 / L1=4 / L0=1 |

### 视频分析加分（v3.5 新增，仅增量库/未在库达人，最多 +20，总分封顶 100）

- 前三个视频中有**带货/产品植入**：+5/个，最多 +15
- 内容形式为**口播/测评/种草**：+5
- 任一视频**播放量 >10 万**：+5

> **存量库名单不加分**（保持 80 分制口径不变）。工具按上传名单里的「**来源**」列区分：
> 该列填「存量/库存/已合作」按存量口径；填「增量」按增量口径加分；不填或其他一律按
> 「未在库新达人」处理（同样走视频加分）。每条结果都会标注 `数据来源`：存量库/增量库/未在库。
> 视频抓取失败（主页 404/权限/结构变化）不影响打标，视频分析留空、按基础分输出。

**分层**：≥60 分 🥇标杆 ｜ ≥40 分 🥈主力 ｜ ≥20 分 🥉潜力 ｜ <20 分 ⚪储备

人设标签、内容形式、行业标签均按存量达人库的固定选项输出（视频内容方向只**补充**不覆盖），结果 CSV 可直接回填达人库。每条结果的「打标依据」里含 `视频分析: [标题1][标题2]…` 与 `数据来源`。

## 系统要求

- **Node.js 18 或以上**（https://nodejs.org）
- **Google Chrome 或 Microsoft Edge**（Windows 10/11 自带 Edge；用于登录与后台抓取）
- Windows 10/11 或 macOS 12+（Intel / Apple Silicon 均可）
- 方式 A 需要能弹出浏览器窗口；若企业策略禁弹窗，会自动切换到方式 B（网页二维码），无需图形桌面弹窗

## 常见问题

- **双击启动脚本没反应 / 一闪而过**：请先确认已安装 Node.js 18+；Windows 可在文件夹地址栏输入 `cmd` 回车后运行 `node xc-tagger.js` 查看报错。
- **Mac 提示「无法打开/已损坏，无法验证开发者」**：在 `start-xc-tagger.command` 上**右键 → 打开**，确认一次即可；或在「系统设置 → 隐私与安全性」里点「仍要打开」。
- **点「登录星图」后没有弹出浏览器窗口 / 窗口一闪就关**：这是企业安全策略拦截了自动启动浏览器，工具会**自动在网页里显示登录二维码**，用手机抖音 App 扫码即可；若网页也没出现二维码，请确认电脑安装了 Chrome 或 Edge。
- **提示「未检测到可用浏览器」**：请安装 Google Chrome（https://www.google.cn/chrome/）或 Microsoft Edge 后重新点「登录星图」。
- **二维码/窗口超时**：登录等待最长 5 分钟，超时后取消并重新点一次「登录星图」即可刷新二维码/重新检测。
- **打标时提示未登录**：登录态可能已过期，重新点「🚀 登录星图」登录即可。v3.4 起工具每 3 秒主动轮询浏览器所有标签页，扫码/账号密码/验证码登录都能即时识别；若你在窗口里登录后网页仍提示未登录，请确认工具为最新版（黑色窗口显示 v3.5.0）。
- **窗口里已登录但工具一直提示未登录（旧版问题）**：v3.4 已修复——新版不再依赖页面内容判断，只看标签页 URL，并会遍历全部浏览器窗口/标签页。若仍出现，关闭所有工具打开的 Chrome/Edge 窗口后重新点一次「登录星图」。
- **v3.5 打标比以前慢**：正常现象——新版会逐个进入达人主页分析前三个视频（每人约 10-15 秒 + 800ms 间隔防风控）。批量打标请耐心等待，中途不要关闭弹出的浏览器窗口。
- **视频分析为空/没有视频加分**：可能是该达人主页无公开作品、访问被限流，或星图页面结构变化；不影响打标，会按基础分输出。需要排查时，可在启动工具前设置环境变量 `XC_TAGGER_DEBUG=1`（.command/.bat 里临时加 `set XC_TAGGER_DEBUG=1` / `export XC_TAGGER_DEBUG=1`），工具会把每个达人主页的截图和接口 JSON 存到工具目录 `.xc-debug/` 文件夹，回传即可校准。

## 隐私说明

- 登录状态保存在工具目录的 `.xc-cookies.json` 文件与 `.xc-chrome-profile` 浏览器配置目录中，**不上传、不落库、不经过任何服务器**；
- 抓取动作发生在你自己的电脑上，工作台网页只与本机 `127.0.0.1:7842` 通信；
- 删除 `.xc-cookies.json` 文件即退出登录。
