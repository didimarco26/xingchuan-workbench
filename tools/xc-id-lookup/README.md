# xc-id-lookup · 星川达人信息互查工具 v1.1.0

> 本机一键工具：给一行达人名单（**抖音号 / 星图ID / 达人名称，任意一列或多列，不必齐全**），
> 工具复用您本机**真实星图官网登录态**批量检索，为每一行补全身份三元组：
> **抖音号 + 星图ID + 达人名称**。
>
> v1.1.0 起支持两种名单来源：
> - **🗂️ 多维表格直连（推荐）**：粘贴多维表格链接 → 读取名单 → 互查后**一键写回表格**；
> - **📄 Excel / CSV**：上传文件 → 互查后导出完整对照表（Excel / CSV）。
>
> 本工具**只做身份信息补全，不做打分评级**。

---

## 一、它解决了什么（为什么不用在多维表格里直接登录）

在飞书多维表格插件里模拟星图短信登录会被星图官方拦截（实测返回「该应用无权限」），
浏览器同源策略也禁止网页读取星图登录 Cookie。因此本工具采用**本机方案**：

- 工具运行在您自己的电脑上，双击启动后会**打开真正的星图官网登录页**；
- 您用**官网任意方式**登录（账号密码 / 扫码 / 短信验证码均可），全程不需要复制 Cookie；
- 工具复用这次真实登录完成检索；多维表格的读取与写回由后端安全完成，本机不持有飞书密钥。

## 二、快速开始（3 分钟）

### Mac 用户
1. 双击解压 `mac-v1.zip`（或通用包 `xc-id-lookup-v1.zip`）；
2. 进入解压后的文件夹，双击 **`start-xc-id-lookup.command`**；
3. 若提示「无法打开，因为来自身份不明的开发者」：右键点该文件 → **打开** → 再点「打开」即可；
4. 工具会自动打开浏览器页面，按页面 **4 步**操作即可。

> 🍎 **Mac 零安装 Node**：电脑上没有 Node.js 也没关系。启动脚本会在首次运行时按芯片
> （Apple Silicon / Intel）自动下载官方 Node 运行环境（约 37MB，从国内可直连的火山引擎 TOS 下载，
> 失败自动切换 npmmirror / nodejs.org 官方源），不需要管理员密码。

### Windows 用户
1. 解压 `win-v1.zip`（或通用包 `xc-id-lookup-v1.zip`）；
2. 双击文件夹内的 **`start-xc-id-lookup.bat`**；
3. 若提示找不到 Node.js，请先到 <https://nodejs.org> 下载安装 LTS 版（勾选 Add to PATH），再双击启动；
4. 工具网页会自动打开。

> 启动后请**保持黑色终端窗口开启**；关闭窗口（或按 Ctrl+C）即停止工具。

## 三、4 步操作

1. **登录星图**：点「🚀 登录星图」，在弹出的 Chrome / Edge 窗口里用官网方式完成登录（页面提示 ✅ 即可）；
2. **选择名单**：
   - **多维表格**：粘贴表格链接 →「读取表格」→ 确认三列字段映射 →「使用这份名单」；
   - **Excel / CSV**：把文件拖入虚线框即可；
3. **开始互查**：点「🔍 开始互查」，逐条检索并实时显示进度；
4. **写回 / 导出**：多维表格来源点「☁️ 一键写回多维表格」；也可随时「⬇️ 导出 Excel / CSV」。

## 四、多维表格直连与写回权限

### 粘贴的链接长什么样
在多维表格里**点进具体数据表**后复制浏览器地址，形如：
`https://xxx.feishu.cn/base/<app_token>?table=<table_id>`（必须包含 `table`）。

### 为什么有时写回报「无权限 / 91403」
读取名单只需查看权限，但**写回需要该表授予本工具对应的应用编辑权限**。有两种开通方式：

- **方式 A（推荐，表格 owner 自己操作，一次即可）**：
  在目标多维表格右上角 **「···」→「···更多」→「添加文档应用」**，
  在弹出窗口中把**本工具对应的应用**加为协作者（可编辑）。
  窗口只会列出已具备云文档 / 多维表格 API 权限的应用；若在列表中找不到，请用方式 B。
- **方式 B（最省心）**：直接使用**渠道经理提供的、已开通写回权限的互查表**链接，
  粘贴后即可读取并写回，无需自己授权。

> 读取阶段若提示无权限（91402），页面会给出同样的引导。写回只回填**补全得到的值**，不会删除其它内容。

### Excel / CSV 来源说明
支持 `.xlsx` / `.xls` / `.csv`，取**第一个工作表**。表头可模糊识别（不区分大小写）：

| 可识别表头 | 含义 |
| --- | --- |
| `抖音号` / `抖音ID` / `抖音账号` / `douyin` / `unique_id` | 达人抖音号（字母数字串） |
| `星图ID` / `星图达人ID` / `达人ID` / `star_id` / `author_id` / `id` / `uid` | 星图达人 ID（纯数字） |
| `达人名称` / `达人名` / `昵称` / `名字` / `主播名` / `name` | 达人昵称 |

- 三列都可缺，每行至少有一列有值；空行自动跳过；抖音号首尾空格、`@` 自动忽略；
- 只有一个列时按内容自动判别：12 位以上纯数字按星图ID，否则按抖音号；
- 可在网页点「下载填写模板」，或使用随包附带的 `xc-id-template.xlsx`。

## 五、检索口径（三路优先级，命中即止）

| 优先级 | 输入 | 检索方式 |
| --- | --- | --- |
| ① | **星图ID** | 直达达人主页 `/xingtu/author/{id}/`，取 `unique_id`（抖音号）与昵称 |
| ② | **抖音号** | `POST /gw/api/gsearch/basic_search_authors`，`seach_type=101`，精确匹配 |
| ③ | **达人名称** | `POST /gw/api/gsearch/basic_search_authors`，`seach_type=0`（昵称模糊搜索），取第一条 |

**模糊结果过滤**：有名称时，第一条结果的名称必须与给定名称一致才采用；无名称时信任排序取第一条。

- 相同输入自动去重缓存，不重复请求；
- 请求逐条进行并自带间隔限速（约 0.5–1 秒/条），请耐心等待；
- 状态列：`成功` = 三元组已补全；`未检索到` = 三路均未命中（可能未入驻星图、输入有误或名称不一致）。

## 六、导出对照表（Excel / CSV 来源）

- **⬇️ 导出 Excel**：`xc-id-lookup-对照表.xlsx`
- **⬇️ 导出 CSV**：`xc-id-lookup-对照表.csv`（UTF-8 带 BOM，Excel 直接打开不乱码）

导出规则：① 原始列全部保留，原值不覆盖、为空才回填；② 缺失列追加规范列；③ 末两列固定为 `状态`、`匹配方式`。

## 七、登录说明（仅需一次）

- 点「🚀 登录星图」后，工具优先**自动打开系统 Chrome / Edge**，在弹窗里用官网任意方式登录；
- 若企业 IT 策略禁止弹窗，工具会自动改为在**网页显示二维码**，用手机抖音 App 扫码；
- 纯服务商账号若 `/sup/` 被重定向，工具会自动转 `/provider/` 服务商广场判定登录；
- 登录态只保存在本机（`.xc-id-cookies.json` 与浏览器配置目录 `.xc-id-chrome-profile/`），不会上传。

## 八、隐私与安全

- 服务只绑定 `127.0.0.1:7843`，**局域网和外网都无法访问**；
- 名单、Cookie、检索结果留在您的电脑上；检索动作等同于您本人在星图网页操作；
- 多维表格的读取 / 写回通过授权后端完成，本机不接触飞书密钥；
- CORS 仅允许本机页面与指定来源调用。

## 九、常见问题

**Q：一直「未检索到」？**
A：先确认该达人已入驻星图；用同一账号在星图网页手工搜一下。若网页能搜到但工具搜不到，
请按「问题反馈」开启调试模式回传日志。

**Q：写回提示无权限（91403）？**
A：按第四节「方式 A」让表格 owner 添加文档应用，或直接使用渠道经理提供的已授权表格（方式 B）。

**Q：提示「未找到可用浏览器」？**
A：请安装 Google Chrome 或 Microsoft Edge；或在工具目录执行 `npx playwright install chromium` 后重启。

**Q：Mac 双击 .command 闪退？**
A：打开「终端」，把 .command 拖进窗口按回车查看具体报错；通常是隔离属性，工具已自动处理。

**Q：可以和 xc-tagger 同时用吗？**
A：可以。两者端口（7842 / 7843）、Cookie 与配置目录各自独立。

## 十、问题反馈

复现问题前设置环境变量开启调试：

```bash
# Mac/Linux
XC_ID_DEBUG=1 ./start-xc-id-lookup.command
# Windows（cmd）
set XC_ID_DEBUG=1
start-xc-id-lookup.bat
```

工具目录下会生成 `.xc-id-debug/`，连同操作步骤反馈给渠道经理即可（注意先去除名单中的敏感客户信息）。
