# xc-id-lookup · 星川达人信息互查工具 v1.0.0

> 本机一键工具：上传达人名单（**抖音号 / 星图ID / 达人名称，任意一列或多列，不必齐全**），
> 工具复用您本机已登录星图的浏览器批量检索，为每一行补全身份三元组：
> **抖音号 + 星图ID + 达人名称**，完成后导出完整对照表（Excel / CSV）。
>
> 本工具**只做身份信息补全，不做打分评级**。

---

## 一、快速开始（3 分钟）

### Mac 用户
1. 双击解压 `xc-id-lookup-mac-v1.zip`（或通用包 `xc-id-lookup-v1.zip`）；
2. 进入解压后的文件夹，双击 **`start-xc-id-lookup.command`**；
3. 若提示「无法打开，因为来自身份不明的开发者」：右键点该文件 → **打开** → 再点「打开」即可；
4. 工具会自动打开浏览器页面。按页面提示：**登录星图 → 上传名单 → 开始互查 → 导出对照表**。

> 🍎 **Mac 零安装 Node**：电脑上没有 Node.js 也没关系。启动脚本会在首次运行时按芯片
> （Apple Silicon / Intel）自动下载官方 Node 运行环境（约 37MB，从国内可直连的火山引擎 TOS 下载，
> 失败自动切换 npmmirror / nodejs.org 官方源），不需要管理员密码。

### Windows 用户
1. 解压 `xc-id-lookup-win-v1.zip`（或通用包 `xc-id-lookup-v1.zip`）；
2. 双击文件夹内的 **`start-xc-id-lookup.bat`**；
3. 若提示找不到 Node.js，请先到 <https://nodejs.org> 下载安装 LTS 版（勾选 Add to PATH），再双击启动；
4. 工具网页会自动打开，按页面提示操作即可。

> 启动后请**保持黑色终端窗口开启**；关闭窗口（或按 Ctrl+C）即停止工具。

## 二、名单文件格式

支持 `.xlsx` / `.xls` / `.csv`，取**第一个工作表**。表头建议使用以下名称（可任选一列或多列）：

| 可识别表头（不区分大小写、支持模糊匹配） | 含义 |
| --- | --- |
| `抖音号` / `抖音ID` / `抖音账号` / `douyin` / `unique_id` | 达人抖音号（字母数字串） |
| `星图ID` / `星图达人ID` / `达人ID` / `star_id` / `author_id` / `id` / `uid` | 星图达人 ID（纯数字） |
| `达人名称` / `达人名` / `昵称` / `名字` / `主播名` / `name` | 达人昵称 |

示例：

| 抖音号 | 星图ID | 达人名称 |
| --- | --- | --- |
| dy_demo001 | 7299999999999999999 | 示例达人A |
| dy_demo002 |  | 示例达人B |
|  | 7299999999999999998 |  |
|  |  | 示例达人C |

- 三列都可以缺，只要每行至少有一列有值；
- 空行自动跳过；抖音号首尾的空格、`@` 自动忽略；
- 只有一个列时，工具会按内容自动判别：12 位以上纯数字按星图ID，否则按抖音号。

可在工具网页点「下载填写模板」获取模板，也可使用随包附带的 `xc-id-template.xlsx`。

## 三、检索口径（三路优先级，命中即止）

| 优先级 | 输入 | 检索方式 |
| --- | --- | --- |
| ① | **星图ID** | 直达达人主页 `/xingtu/author/{id}/`，取 `unique_id`（抖音号）与昵称 |
| ② | **抖音号** | `POST /gw/api/gsearch/basic_search_authors`，`seach_type=101`，精确匹配 |
| ③ | **达人名称** | `POST /gw/api/gsearch/basic_search_authors`，`seach_type=0`（昵称模糊搜索），取第一条 |

**模糊结果过滤**：有名称时，第一条结果的名称必须与给定名称一致才采用；无名称时信任排序取第一条。

- 相同输入自动去重缓存，不重复请求；
- 请求逐条进行并自带间隔限速（约 0.5–1 秒/条），请耐心等待；
- 状态列说明：`成功` = 三元组已补全；`未检索到` = 三路均未命中（可能未入驻星图、抖音号/名称有误或检索结果名称不一致）。

## 四、导出对照表

互查完成后点页面上的：

- **⬇️ 导出 Excel**：`xc-id-lookup-对照表.xlsx`
- **⬇️ 导出 CSV**：`xc-id-lookup-对照表.csv`（UTF-8 带 BOM，Excel 直接打开不乱码）

导出规则：

1. 原始列全部保留，原列为空时用补全值回填，已有值不覆盖；
2. 原本不存在的列追加规范列（抖音号 / 星图ID / 达人名称）；
3. 末两列固定为 `状态` 与 `匹配方式`。

## 五、登录说明（仅需一次）

- 点「🚀 登录星图」后，工具优先**自动打开系统 Chrome / Edge**，在弹出的窗口里扫码或用账号登录即可；
- 若企业 IT 策略禁止弹出窗口，工具会自动改为在**网页上显示登录二维码**，用手机抖音 App 扫码；
- 纯服务商账号若 `/sup/` 被重定向，工具会自动转 `/provider/` 服务商广场判定登录；
- 登录态只保存在本机（`.xc-id-cookies.json` 与浏览器配置目录 `.xc-id-chrome-profile/`），不会上传。

## 六、隐私与安全

- 服务只绑定 `127.0.0.1:7843`，**局域网和外网都无法访问**；
- 名单、Cookie、检索结果全部留在您的电脑上，工具不会把数据发送到任何第三方服务器；
- 检索动作通过您本机已登录星图的浏览器完成，等同于您本人在星图网页操作；
- CORS 仅允许 `didimarco26.github.io` 与本机页面调用。

## 七、常见问题

**Q：一直「未检索到」？**
A：先确认该达人已入驻星图；用同一账号在星图网页手工搜一下抖音号/名称。若网页能搜到但工具搜不到，
请按下面「问题反馈」开启调试模式回传日志。

**Q：提示「未找到可用浏览器」？**
A：请安装 Google Chrome 或 Microsoft Edge；或在工具目录执行 `npx playwright install chromium` 后重启。

**Q：Mac 双击 .command 闪退？**
A：打开「终端」，把 .command 拖进窗口按回车，可看到具体报错；通常是隔离属性，工具已自动处理。

**Q：可以和 xc-tagger 同时用吗？**
A：可以。两者端口（7842 / 7843）、Cookie 与配置目录各自独立。

## 八、问题反馈

复现问题前设置环境变量开启调试：

```bash
# Mac/Linux
XC_ID_DEBUG=1 ./start-xc-id-lookup.command
# Windows（cmd）
set XC_ID_DEBUG=1
start-xc-id-lookup.bat
```

工具目录下会生成 `.xc-id-debug/`，将其连同操作步骤反馈给渠道经理即可（注意先去除名单中的敏感客户信息）。
